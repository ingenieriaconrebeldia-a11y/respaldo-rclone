# Política de privacidad - Respaldo Rclone

## Finalidad
Esta aplicación es de uso personal y permite realizar copias de seguridad de Google Drive en un disco local mediante Rclone.

## Acceso a los datos
La aplicación utiliza Google Drive API con permisos de solo lectura para consultar y descargar archivos.

## Almacenamiento
Los archivos descargados se guardan localmente en el equipo del usuario.

Las credenciales de autorización se almacenan localmente mediante Rclone.

## Uso y privacidad
La aplicación no comercializa ni comparte los archivos del usuario con terceros. No utiliza servidores propios para almacenar los documentos.

## Revocación del acceso
El usuario puede revocar los permisos desde la configuración de seguridad de su cuenta de Google.
